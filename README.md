# Portfolio Project

This is a personal portfolio web application built using Streamlit. It showcases projects, skills, and certifications related to data analytics and programming.

## Features

* About Me section
* Skills section
* Projects section
* Certifications section
* Contact section

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* PostgreSQL

## Projects Included

1. Interactive Data Visualization Learning Platform
   A Streamlit-based application to learn data visualization concepts with real-time examples.

2. Student Registration System
   A backend-focused web application using Python and PostgreSQL with CRUD operations.

3. Exploratory Data Analysis on Kaggle Dataset
   Data cleaning, preprocessing, and visualization to extract insights.

4. Power BI Dashboard
   Interactive dashboard for business data analysis and reporting.

## Installation

1. Clone the repository:
   git clone https://github.com/yourusername/your-repo-name.git

2. Navigate to the project folder:
   cd your-repo-name

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   streamlit run app.py

## Deployment

The application can be deployed using Streamlit Cloud or Render.
